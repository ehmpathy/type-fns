# case 11 — a payload is frozen in place

> a declared composite: **C01** happy·criti at `[t0]` · **C02**, **C05** happy·alter at `[t1-t2]`.

## .the narrative

lin authors the sdk's handler contract. the type already says `payload: FrozenDeep<TPayload>`, but a
type is a promise the runtime does not keep: a consumer who holds the original reference can still
write to it. she wants the runtime to agree with the type, in one line, at the seam where the
payload enters.

```ts
const payload = asFrozenDeep(JSON.parse(event.body));
```

the call hands back **the same object**, frozen all the way down, typed `FrozenDeep<T>`. no copy, so
no second reference drifts from the first. a branded stamp inside it comes back a stamp.

she reads through it as before. the walk invoked no getter, so a lazy prop stays lazy. a retry
calls `asFrozenDeep` on the value again; it returns the same reference and throws naught.

### the aha

> one call makes the runtime keep the type's promise, and costs no copy.

## .the bdd sketch

```gherkin
given a payload with a brand, a nested object, and a map

  [t0] when asFrozenDeep freezes it                                  # C01, happy critipath
       then it returns the same reference
        and every object in the graph is frozen
        and the brand is intact — assignable back to IsoTimeStamp

  [t1] when the author reads through it                              # C02, happy alterpath
       then every read returns what it held; no getter ran

  [t2] when asFrozenDeep is called again on it                       # C05, happy alterpath
       then it returns the same reference, no throw
```

## .where it is proven

- `src/index.acceptance.test.ts` `[case3] [t0]` — against the built package: same reference, frozen,
  brand intact, a snapshot of the frozen value, and the second call.
- `src/companions/asFrozenDeep.test.ts` — the getter is never invoked; cycles and shared sub-objects
  freeze once.

## .why a critipath

if `[t0]` broke, the sdk's promise of a frozen payload would be a type-only claim again — the gap
the companion exists to close. no workable fallback short of a hand-rolled deep freeze, which is
what `Object.freeze` already fails to be for a `Map`.
