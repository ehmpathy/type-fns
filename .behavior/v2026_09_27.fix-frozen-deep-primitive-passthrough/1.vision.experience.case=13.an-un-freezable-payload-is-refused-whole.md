# case 13 — an un-freezable payload is refused whole

> **C11**, sharp·criti.

## .the narrative

lin's sdk freezes each event before it reaches a handler. one event carries raw bytes three levels
down, as a `Uint8Array`. no freeze can make a typed array with elements hold — the engine refuses
`Object.freeze` on it outright.

a partial freeze would be the worst outcome: half the graph frozen, the rest not, and no way for the
caller to tell which half. so `asFrozenDeep` checks the whole graph first, and refuses before it
freezes any of it:

```
✋ ConstraintError: asFrozenDeep can not freeze a typed array with elements
{
  "path": "value.event.records[0].raw",
  "kind": "Uint8Array",
  "byteLength": 1,
  "hint": "convert it to a plain array first, e.g. Array.from(bytes)"
}
```

the `path` points at the one object to fix. the hint names the fix. the input is untouched — not
frozen, still writable — so she can convert the bytes and call again.

the same shape of refusal covers each un-freezable kind: a global or sticky `RegExp`, and a `Map` or
`Set` sealed by some other freeze or with a pinned own mutator.

### the aha

> all or none: the error names where, and what to do, and leaves naught half-frozen.

## .the bdd sketch

```gherkin
given a payload that holds an un-freezable object, deep

  [t0] when asFrozenDeep is called on it                             # C11, sharp critipath
       then a ConstraintError names the path, the kind, and the fix
        and no object in the graph is frozen
```

## .where it is proven

- `src/index.acceptance.test.ts` `[case4]` — four refusals against the built package (a typed array
  deep, a global `RegExp` under a map value, a sealed `Set`, a pinned `Map`), each with its path
  asserted and snapshotted, each input left un-frozen.
- `src/companions/asFrozenDeep.test.ts` — every path form (own prop, array index, quoted key, symbol,
  map value per key kind, map key, set member).

## .why a critipath

if the refusal were partial, a caller could not trust any object in the graph. if it named no path,
a deep payload would cost a hunt. either break turns a fixable input into a debug session.
