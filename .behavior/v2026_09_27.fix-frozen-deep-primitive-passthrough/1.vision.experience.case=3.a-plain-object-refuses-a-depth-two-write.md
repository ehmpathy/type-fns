# case 3 — a plain object refuses a depth-two write

> cells **A56** `[t0]` · **A60** `[t1]` · **A10** + **A20** `[t4]` ·
> feel **sharp** · care **critipath** (A20 at `[t4]`: **alterpath**) · the guarantee the type
> exists for · a **declared composite** (see the inventory's composite table)

## .the narrative

jo writes a lambda handler. the envelope arrives frozen, and jo sets a default on it out of habit:

```ts
invoke: async ({ event }) => {
  event.page.limit = 50;   // "just a default"
  return await search(event);
};
```

under typescript's `Readonly<T>`, that line **compiles**. `Readonly` is one level deep:
`event.page` is readonly, every slot inside it is open. the runtime freeze is deep, so the assign
throws `TypeError: Cannot assign to read only property 'limit'` — a 500 in production, on a line
the compiler approved.

under `FrozenDeep`, `tsc` refuses the line at the keyboard:

```
Cannot assign to 'limit' because it is a read-only property.
```

jo reads it once — the envelope is frozen, so copy it — and moves on.

### the aha

> the type and the freeze must agree at **every** depth, or the type lies at exactly the depths it
> does not reach.

`Readonly` lies from level two down; that is why `FrozenDeep` exists. a regression here makes the
type *more* permissive, and a more permissive type breaks no test that does not look for it.

⇒ this clamp guards what the fix must not break. the primitive arm sits above the object arm; a
predicate written too wide would divert objects into the passthrough and delete the guarantee.

## .the bdd sketch

```gherkin
given a plain object nested two levels deep, typed FrozenDeep

  [t0] when the author writes to a depth-two property
       then tsc refuses it
        and the message names the property as read-only

  [t1] when the author writes to a depth-one property
       then tsc refuses it too

  [t2] when the author READS the same depth-two property
       then it compiles — the refusal is on the write, never the read

  [t3] when the object carries a branded primitive alongside
       then the write is still refused
        and the branded primitive is still assignable back
        (the fix loosens identity, never the guarantee)

  [t4] when the author writes to a slot whose value is a PRIMITIVE
       then tsc refuses it — plain or branded alike
        (the readonly sits on the slot, never on the value type)
```

```ts
// [t0] — the wish's third clamp assertion, verbatim
// @ts-expect-error
({} as FrozenDeep<{ x: { y: number } }>).x.y = 1;

// [t1] — depth one refuses too
// @ts-expect-error
({} as FrozenDeep<{ x: { y: number } }>).x = { y: 1 };

// [t2] — reads are untouched
const read: number = ({} as FrozenDeep<{ x: { y: number } }>).x.y;

// [t3] — the two guarantees coexist. this is the regression guard on the fix itself
type Stamp = string & { _dglo: 'iso-time.IsoTimeStamp' };
const both = {} as FrozenDeep<{ at: Stamp; page: { limit: number } }>;
const stampOut: Stamp = both.at;
// @ts-expect-error - the write is still refused
both.page.limit = 50;

// [t4] — a slot whose VALUE is a primitive. cells A10 and A20
// @ts-expect-error - plain
({} as FrozenDeep<{ s: string }>).s = 'x';
// @ts-expect-error - branded. the fix must not open this
({} as FrozenDeep<{ at: Stamp }>).at = '' as Stamp;
```

`[t0]`–`[t2]` restate a guarantee that already holds. the two steps that earn their place:

- **`[t3]`** fails if the primitive arm's predicate is too wide — the most plausible way to get this
  fix wrong. it guards a **neighbour** of a branded primitive.
- **`[t4]`** guards the branded primitive's **own slot** — the slot the fix reaches into, and the
  nearest cell to the change. measured in `appendix/…probe.peer-round-1.md`, round 1b.

## .why it is a critipath

- **freq** — every handler, every envelope, every service. the default read path.
- **cost** — a runtime `TypeError` on a line the compiler blessed: the type system was consulted
  and said yes.
- **silent regression risk** — a loosened `FrozenDeep` breaks no test that does not assert a
  refusal. without this clamp, the guarantee can vanish on a green suite.
