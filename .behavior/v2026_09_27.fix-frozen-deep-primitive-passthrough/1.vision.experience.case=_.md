## .the legend

| verdict | sense |
|---------|-------|
| **demoed** | a real experience, demonstrated in a `case=N` file |
| **itemized** | a real experience, on record, not demoed |
| **forbidden** | attemptable; the behavior must reject it (a rejection invariant) |
| **impossible** | no attempt is possible — void by nature |

one verdict per cell, the first token of the column. on a `forbidden` cell, a suffix `· itemized` or
`· demoed → case N` is **demo status**, never a second verdict.

**feel** = `happy` / `sharp` · **care** = `criti` / `alter` (`freq × cost`).

**the feel rule.** `happy` = the type gives the author what its contract owes. `sharp` = it answers
otherwise — a refusal, or a silent pass where a refusal or a narrower type was owed. a write that
compiles on a "frozen" value is `sharp`; A53/A54 are `happy`, since the wish requires a frozen
object to assign back.

**⚠️ misleads** in the note column marks a diagnostic that teaches the wrong lesson. that is
diagnostic quality, not feel (`dimensions.md`, "the two feel values").

**forbidden and demoed coexist.** a write refusal is an invariant the checker owes AND the lived
experience of the type. `forbidden` answers *what must the behavior reject?*; the demo link answers
*where is that rejection shown?* the register collects the first; the case files hold the second.

**`impossible` = nature, not nurture.** `tsc` refuses many such lines because the member is absent,
never because `FrozenDeep` withheld it. a behavior is not graded on a refusal it did not author.

### the runtime honest bound

`itemized ⚠️`: what `asFrozenDeep` does not reject, each asserted in `asFrozenDeep.test.ts` so the
bound can not be over-promised, each named in its jsdoc:

| the act | why it passes |
|---------|---------------|
| a write to an `ArrayBuffer`'s bytes through a view built after the freeze | a view reads the buffer's slot, which no freeze reaches |
| `Map.prototype.set.call(frozen, k, v)` | the refusal shadows the own prop; the prototype method is untouched |
| a class method that writes a `#private` field | a private field is not a property; no freeze reaches it |

## .the rejection-invariant register

every `forbidden` cell as a checkable rule — what a verification stage grades against.

| # | the attempt the behavior MUST reject | cells | count |

| **I3** | a **property write** on a frozen object, any depth, exotic included | A55, A56, A65, A66, A75, A76, A85, A86 | 8 |
| **I4** | an **indexed write** into a frozen array or tuple — `arr[0] = x`, `arr.length = n` | A35, A36, A45, A46 | 4 |
| **I5** | a **mutator method** on a frozen array or tuple — `push`, `pop`, `splice`, `sort` | A37, A38, A47, A48 | 4 |
| | | **total** | **27** |

I1 and I2 partition `write-slot × nested` by value type. together they carry the widest rule:
*`readonly` sits on the slot, never on the value* — so the slot holds for a function, a `Map`, an
`unknown`, and an `any` alike.

in the shipped type, F3 and F6 add A77/A78 and A25/A26 as rejection invariants.

### the honest bound — what #48's type does NOT reject

`itemized ⚠️`, never `forbidden`: the perimeter of the word "frozen".

| the attempt | why it passes | fulcrum |
|-------------|---------------|---------|
| a property write **onto a function** (A25, A26) | the function arm maps no key | F6 — closed by verdict in the shipped type |
| a **mutator method** on a `Map`/`Set` (A77, A78) | the mapped type keeps methods | F3 — closed by verdict in the shipped type |
| an assign into a **mutable object sink** (A53, A54) | typescript ignores `readonly` in structural assignability | F4 |
| any write **through `any`** (A105–A108) | `any` opts out of every check | — by design of `any` |

the rows that stay open are what F4's jsdoc bound must state, or the register reads as a stronger
promise than the type makes.

🔴 **one hole no cell holds, since it is a narrow, not a shape:** `Array.isArray(frozen)` hands
`.push` back. the guard's `arg is any[]` intersects the mutable array back in; a `typeof` narrow
keeps the refusal. typescript's lib does this, never `FrozenDeep`; the jsdoc names it, since
`Array.isArray` is the common guard.
