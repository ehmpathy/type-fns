# 1.vision.experience.dimensions — `FrozenDeep<T>`

## .what

the axes the `FrozenDeep<T>` experience varies over, and the product walked from them. the
inventory that verdicts every cell: `1.vision.experience.case=_.md`. how the grid reached this
shape: `appendix/inventory.how-the-grid-changed.md`.

the axes describe #48's type as measured. the wisher's verdicts (F3, F6, F9 — see
`1.vision.yield.md`) change the outcome of some cells in the shipped type, never the axes.

## .the frame

`FrozenDeep` is a type, so boxes A and B are compile-time: a red squiggle appears, or it does not.
the felt unit: **an author runs `tsc` and reads what it says.** the companion `asFrozenDeep`
(the wisher's ask, 2026-09-28) adds one runtime box, C: the felt unit there is **a call returns,
or throws, and the author reads what it says.**

`feel` has two values, `happy` and `sharp`. whether an error teaches the right lesson is
diagnostic quality, not feel — it rides as a `⚠️ misleads` marker in the inventory's note column
(columns: `# | operation | depth | verdict | feel | care | note`). the defect this wish closes is a
`sharp` cell that carries `⚠️ misleads`.

## .two boxes

| box | the encounter | varies over |
|-----|---------------|-------------|
| **A — the type's behavior** | an author holds a `FrozenDeep<T>` value and acts on it | shape, operation, depth. the actor never changes the answer |
| **B — the package surface** | a person obtains, declares, or verifies the type | actor, goal. the shape never enters |
| **C — the runtime companion** | an author calls `asFrozenDeep(value)`, then acts on what it returned | reach, act. the type-level shape is box A's |

one product `actor × shape × operation × depth` = 330 cells, nearly all duplicates — the checker
does not know who asks. `actor` fails orthogonality in box A, so it lives in box B.

the boxes stay disjoint. rule: **a box-B cell whose content is a box-A outcome belongs to box A.**
so B06 (`consumer × verify`) is the consumer's repo build after the sdk bump and patch removal — a
release-path experience with no box-A cell behind it.

## .box A — the type's behavior

### 1. `shape` — what `T` is (11 values, closed)

the axis the conditional type switches on.

| value | example | arm under #48 |
|-------|---------|---------------|
| `primitive-plain` | `string`, `number`, `null`, every literal | final `: T`; the primitive arm once added |
| `primitive-branded` | `IsoTimeStamp` = `string & OfGlossary<…>` | **object arm — the defect**; the primitive arm once added |
| `function` | `(a: number) => void` | function arm |
| `array` | `number[]`, `readonly Foo[]` | array arm |
| `tuple` | `[since: string, until: string]` | array arm — degrades to `readonly string[]` |
| `object-plain` | `{ x: { y: number } }`, an index signature, a symbol key | object arm |
| `object-branded` | `{ at: string } & OfGlossary<…>` | object arm |
| `object-exotic` | exemplar `Map`; the family `Date`, `Set`, `RegExp`, `WeakMap`, typed arrays, `Error`, `Promise`, a class instance | object arm |
| `union` | `string \| { y: number }` | distributes per member |
| `opaque` | `unknown`, `never`, `void` | no arm; no surface to act on |
| `any` | `any` | opts out of every check; a freeze has no reach past it |

- **`tuple` is its own value**: it takes the array arm and lands on a different answer — length,
  labels, and positions gone (`appendix/groundwork.probe.tuple-arm.md`). one arm, distinct
  outcome, distinct shape.
- **`object-exotic` closes by arm membership, not by list**: every object that is not a function,
  array, or plain record. members agree on the property reach and differ on the method reach —
  that difference is `has-mutator-surface`, below. six members beyond `Map` were fed to `tsc`; each
  took the exemplar's answer for its reach (`appendix/groundwork.probe.peer-round-4.md`).
- **`opaque` and `any` are two values**: through `any` every write compiles, at the top and past a
  readonly slot; `unknown` / `never` / `void` refuse. they are the boundary of the shape space, so
  neither folds into `primitive-*` or `object-*`. `opaque` write cells are `impossible`; `any`
  write cells compile under a "frozen" name.

#### the latent `brand` dimension

`primitive-plain` · `primitive-branded` · `object-plain` · `object-branded` encode
`brand` = `{un-branded, branded}` in their names. it stays latent, and the reason is measured:

| | `un-branded` | `branded` | differ? |
|---|---|---|---|
| **primitive** | primitive arm | object arm under #48 | 🔴 yes — the whole defect |
| **object** | object arm | object arm | no — the brand rides along (variance row F) |
| function · array · tuple · object-exotic · union · opaque · any | — | no probed inhabitant | — |

nine kinds with the brand factored out; `kind × brand` = 18 columns. 7 branded columns have no
probed inhabitant, and the object pair is identical. a split adds void region and removes no
correlation. **the debt**: if a branded array or branded function is ever probed and diverges,
`brand` earns promotion.

#### closure — every input class lands on a value

closed means every input class lands on a value; it does not mean every class was compiled. the
two tables keep probed and argued apart.

| probed input | value | why |
|--------------|-------|-----|
| a literal — `'shredder'` | `primitive-plain` | not widened; same arm |
| an index signature — `Record<string, number>` | `object-plain` | the indexed slot refuses a write, as a named key does |
| a symbol key — `{ [sym]: T }` | `object-plain` | mapped, never dropped; the slot refuses a write |
| an optional property — `{ a?: T }` | not a shape | a property modifier, kept by the homomorphic map (premise 14) |
| a recursive type — `TreeNode` | `object-plain` | terminates and goes deep (edge E4) |
| `unknown` · `never` · `void` | `opaque` | no surface to act on |
| `any` | `any` | every write compiles |
| `WeakMap` · `Uint8Array` · `Error` · `Promise` · a class instance | `object-exotic` | each takes the exemplar's answer for its reach |
| a class with `#private` fields | `object-exotic` | measured (E8): the map drops privates, so assign-back is refused |
| a branded number or boolean | `primitive-branded` | the brand is the axis, not the primitive under it (edge E7, E8) |

| argued input | value | the collapse |
|--------------|-------|--------------|
| a nested generic — `Foo<Bar<Baz>>` | the value of what it expands to | the checker expands a generic before the mapped type sees it — a depth question, never a shape one |
| a conditional type — `A extends B ? X : Y` | same | `FrozenDeep`'s arms see the expanded type |

the two argued rows are collapses by argument, not by a `tsc` run.

### 2. `operation` — what the author does (5 values)

| value | the act | tests |
|-------|---------|-------|
| `read` | `event.at`, `arr[0]` | the type still exposes what it should |
| `assign-back` | `const x: Stamp = frozen`, or pass to `(x: Stamp) => …` | the type kept identity |
| `write-property` | `frozen.y = 1`, `arr[0] = 1`, `map.size = 1` | mutate in place via a property |
| `write-method` | `arr.push(1)`, `map.set(k, v)` | mutate in place via a mutator method |
| `write-slot` | `frozen.a = {…}` | reassign the slot that holds a value |

**property and method reach are two values** because one shape at one depth answers both ways
(`appendix/groundwork.probe.peer-round-2.md`):

| assertion | reach | #48 verdict |
|-----------|-------|-------------|
| `frozenMap.size = 1` | property | ⛔ refused |
| `frozenMap.set('a', 1)` | method | ✅ permitted |

under #48, `FrozenDeep` is a property-level guarantee: total on the property reach, silent on the
method reach. F3 closes the method reach in the shipped type.

**`write-property` and `write-slot` are two values** because each act is available at both
depths and neither implies one (`appendix/groundwork.probe.peer-round-1.md`). a fused `write`
would make the operation's sense depend on depth — a correlation.

### 3. `depth` — where the leaf sits (2 values)

| value | example |
|-------|---------|
| `top` | `FrozenDeep<Stamp>` |
| `nested` | `FrozenDeep<{ page: { since: Stamp } }>` |

where `FrozenDeep` parts from typescript's `Readonly`: at `top` they agree, at `nested` they
diverge. svc-chat's `page.range.since.lastMessageAt` sits three levels down.

### orthogonality, and two constraints

- **shape ⟂ depth** — any leaf shape sits at the top or inside a container.
- **shape ⟂ operation** — neither predicts the other.
- **operation ⟂ depth** — each operation is available at either depth, with the same sense.

two constraints void regions. a constraint removes cells; it is not a correlation, since neither
axis predicts a value of the other.

#### `slot-context` voids `write-slot × top`

`write-slot × top` is `impossible` for all eleven shapes (A09, A19, A29, A39, A49, A59, A69, A79,
A89, A99, A109).

> **`slot-context` = `{is-a-slot, is-a-root}`.** `write-slot` assigns into a container's slot. a
> root `FrozenDeep<T>` value is a variable — a `const` or a parameter — not a slot. `top` is
> exactly `is-a-root`.

`top` still hosts read, assign-back, write-property, and write-method; `write-slot` still hosts
`nested`. the same species as box B's `authorship`.

#### `has-mutator-surface` voids `write-method` for 7 of 11 shapes

`write-method` is live for 4 of 11 shapes — `array`, `tuple`, `object-exotic`, `any`.

> **`has-mutator-surface` = `{carries-a-mutator, carries-none}`.** a primitive, a function, a plain
> or branded object, a union, and the `opaque` values expose no own mutator. no attempt exists, so
> the cell is `impossible` by nature, not by refusal. `any` carries every member, a mutator among
> them.

the constraint is borne by a member, not always by its shape. inside `object-exotic`, `Map`
carries a mutator; `Error` and `Promise` carry none. the shape's `write-method` cells record the
`Map` exemplar; a mutator-free member lands on `impossible`. a `union` owns no live cell here:
un-narrowed, the reach fails for want of a member; narrowed, the value leaves the union for its
member's row.

the partly-void column is the price of the property/method split, and it is worth it: a void
derived from a nameable property beats one cell that holds two measured verdicts.

### the product

**11 shapes × 5 operations × 2 depths = 110 cells.**

### `provenance` — a column, not an axis (F5)

`provenance` = `{sdk-local declaration, type-fns import}` is the before/after contrast, not a
property of a live experience; it has one value once this ships. as an axis it would double 110
cells to change two — the `primitive-branded × assign-back` pair. it rides as a column on those
two inventory rows, where the clamp lives.

## .box B — the package surface

### the axes

| `actor` | who |
|---------|-----|
| `contract-author` | declares a slot as `FrozenDeep<T>` (sdk-aws-lambda) |
| `consumer` | depends on such a contract (svc-chat) |
| `maintainer` | changes or verifies the type (type-fns) |

| `goal` | what they came for |
|--------|--------------------|
| `obtain` | get the type into their file |
| `declare` | put it on a slot of their own contract |
| `verify` | prove it still holds |

### orthogonality, and one constraint

`actor` and `goal` are orthogonal as axes: no goal implies an actor, and no actor's goals are a
subset of another's. one constraint voids two cells:

| cell | why void |
|------|----------|
| `consumer × declare` (B05) | a consumer receives a contract; to author it would make them a contract-author |
| `maintainer × obtain` (B07) | a maintainer is the source; no obtain step exists from where they stand |

> **`authorship` = `{authors-the-contract, receives-the-contract}`.** each actor sits at a fixed
> point on it, so exactly two cells void.

### the product

**3 actors × 3 goals = 9 cells.**

## .box C — the runtime companion

### the axes

| `reach` | what the value's graph holds | example |
|---------|------------------------------|---------|
| `plain` | objects, arrays, functions, primitives, an empty typed array — a bare `Object.freeze` seals them whole | `{ page: { limit: 10 }, tags: [] }` |
| `slot-mutator` | a built-in whose mutators write an internal slot, so a bare freeze leaves them live | `Map`, `Set`, `WeakMap`, `WeakSet`, `Date`, `DataView`, `RegExp`, `ArrayBuffer` |
| `un-freezable` | a value no freeze can make hold, or one sealed out of reach | a typed array with elements, a global or sticky `RegExp`, a `slot-mutator` kind sealed elsewhere or with a pinned own mutator |

| `act` | what the author does |
|-------|----------------------|
| `freeze` | calls `asFrozenDeep(value)` |
| `read` | reads through the returned value — props, `map.get`, `date.getTime` |
| `write-property` | assigns a prop through any reference to the frozen graph |
| `call-mutator` | calls a mutator — `arr.push`, `map.set`, `date.setFullYear` |
| `re-freeze` | calls `asFrozenDeep` again on a value already frozen by it |

`reach` classifies the **worst** object the graph holds: one `un-freezable` object makes the whole
call `un-freezable`, since the companion freezes all or none. the closed list of `slot-mutator`
kinds lives in `kindsWithSlotMutators`, and a doc-drift clamp holds the docs to it.

### orthogonality, and one constraint

`reach` ⟂ `act`: no act implies a reach. one constraint voids four cells:

> **`frozen-value-exists` = `{returned, refused}`.** an `un-freezable` call throws and returns
> naught, so `read`, `write-property`, `call-mutator`, and `re-freeze` have no frozen value to act
> on (C12–C15). the input stays as it was — not frozen, still writable.

### the product

**3 reaches × 5 acts = 15 cells.** with boxes A and B: **134 cells**.

### the latent dimensions of box C

| latent dimension | values | why not an axis |
|------------------|--------|-----------------|
| `graph-shape` | tree / shared sub-object / cycle | all three answer alike: each object freezes once, a cycle terminates. measured in `asFrozenDeep.test.ts` |
| `path-depth` | root / nested / under a map key or set member | shapes only the `path` field of a refusal, never its verdict. measured per path form |
| `holder` | the returned reference / the original reference / another holder | one object, frozen in place — every holder sees the freeze |

## .the density lens

the product guarantees each cell is considered. a cell is one point — one shape, one operation,
one depth — so per-cell demos never exercise how the arms interact.
`define.experience._.metric=boundary-density` grades that: how many boundaries does one walk
cross?

case 8 walks one payload through the primitive, object, and array arms at once, and meets a
second wall: the reported shape compiles, and one array field more refuses a mutable sink
(`appendix/groundwork.probe.dense-envelope.md`, rows A vs C). density is a lens on demos, not an
axis — case 8 adds no cell; it re-walks four demoed cells together.

## .the latent dimensions, declared

each dimension known and not an axis, so the axis set can be audited:

| latent dimension | values | where | why not an axis |
|------------------|--------|-------|-----------------|
| `brand` | un-branded / branded | inside the four `-plain` / `-branded` shapes | live on 1 of 9 kinds; a split adds 7 void columns |
| `has-mutator-surface` | carries-a-mutator / carries-none | voids `write-method` for 7 shapes; varies per member in `object-exotic` | a constraint |
| `slot-context` | is-a-slot / is-a-root | voids `write-slot × top` for all 11 shapes | a constraint |
| `authorship` | authors / receives | voids B05, B07 | a constraint |
| `frozen-value-exists` | returned / refused | voids C12–C15 | a constraint |
| `mutation-surface` | via-property / via-method | promoted — the `write-property` / `write-method` split | one cell held opposite outcomes |
| `knowability` | opaque / permissive | promoted — the `opaque` / `any` split on `shape` | one value answered both ways on one cell |

a named latent dimension can be promoted; an unnamed one must be discovered again.
