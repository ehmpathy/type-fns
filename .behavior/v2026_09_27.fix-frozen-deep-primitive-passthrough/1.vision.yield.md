# 1.vision — `FrozenDeep<T>`, the `Frozen*` family, and `asFrozenDeep`

type-fns exports a deep-readonly type that leaves every primitive — branded primitives included —
exactly as it is, plus a runtime companion that enforces what the type announces.

this route ships the types, the companion, and their release. two acts follow, in other repos: `sdk-aws-lambda` bumps
its pin and imports the type (its step 2), then `svc-chat` drops its pnpm patch. every outcome claim
below is scoped to the first of the three releases.

## the type this route ships

#48's type, with three arms made stricter by the wisher's verdicts (2026-09-28). the principle:
**a general type owes its guarantee past the reported shape.**

| input | #48 as written | shipped |
|-------|----------------|---------|
| primitive, branded or plain | unchanged | unchanged — the fix |
| plain object | deep readonly | deep readonly |
| array | `readonly T[]` | `readonly T[]` |
| tuple `[since, until]` | ⛔ degrades to `readonly string[]` | ✅ stays a readonly tuple — arity, labels, positions kept (F9) |
| `Map` / `Set` | ⚠️ `.set` / `.add` compile | ⛔ `FrozenMap<K, V>` / `FrozenSet<T>` — mutators refused, entries frozen deep (F3) |
| function with own props | ⚠️ a prop write compiles | ⛔ call signature kept, own props readonly (F6) |
| `Date` | round-trips | round-trips |

### the `Frozen*` family

one prefix, one sense: *readonly all the way down*. each name is what a hover shows.

| type | definition | role |
|------|------------|------|
| `FrozenDeep<T>` | the dispatcher above | the entry point; maps any shape to its frozen form |
| `FrozenMap<K, V>` | `ReadonlyMap<FrozenDeep<K>, FrozenDeep<V>>` | what `FrozenDeep<Map<K, V>>` yields |
| `FrozenSet<T>` | `ReadonlySet<FrozenDeep<T>>` | what `FrozenDeep<Set<T>>` yields |

- **built on the lib's readonly interfaces**, so a `FrozenMap` passes wherever a `ReadonlyMap` is
  accepted, and the lib's own method set does the refusal.
- **no `FrozenArray`** — an array keeps `ReadonlyArray<FrozenDeep<T>>` and a tuple keeps its own
  shape (F9), so one name cannot cover both. (F13)
- **one file** — `src/types/FrozenDeep.ts` holds the family, since `FrozenDeep` and `FrozenMap`
  reference each other and split files would form an import cycle. (F14)

### the runtime companion — `asFrozenDeep`

```ts
const event = asFrozenDeep(input);   // same reference, frozen deep, typed FrozenDeep<typeof input>
```

the type announces; the companion enforces. without it, "frozen" is a promise each consumer
implements by hand — `sdk-aws-lambda` already did, and its type and freeze drifted apart into the
defect this wish fixes.

| shape | runtime act |
|-------|-------------|
| primitive | returned as-is |
| plain object, array, tuple | `Object.freeze`, then recurse over own values |
| function | `Object.freeze`, then recurse over own props — the call still works |
| `Map` / `Set` | shadow `set` / `add` / `delete` / `clear` with own props that throw, then `Object.freeze`, then recurse over keys and values (F12) |
| `Date` | `Object.freeze` — same reach as the type: methods stay callable |
| a cycle or a shared sub-object | a `WeakSet` stops the second visit |

- **in place, same reference** (F11) — a copy would break identity (`headers === event.headers`),
  the reason the sdk's own freeze is in place. the return narrows the type; it does not clone.
- **the type and the runtime agree on every shape.** the `Map`/`Set` shadow is what makes the
  runtime refuse `map.set()` as the type does — `Object.freeze` alone would not.
- **placement**: `src/companions/asFrozenDeep.ts`, beside `omit` / `pick` — the house home for a
  runtime companion to a type.

release level: `fix` → patch, per the `HasMaybe` precedent (F10). the same release adds the
`ArrayWith` root export its original commit omitted (F7).

## the outcome world

### day-in-the-life

an app dev adds a lambda endpoint whose payload carries an `IsoTimeStamp`:

```ts
genLambdaEndpoint.forAsk({
  payload: getThreadsByParticipantPayloadSchema,
  invoke: async ({ payload }) => await query(payload),
});
```

`tsc` stays quiet. the stamp goes in a stamp and comes out a stamp. without the fix, the error
claims her `IsoTimeStamp` is not an `IsoTimeStamp` and offers a readonly record of every
`String.prototype` member plus `_dglo`.

### before/after

| | before | after |
|---|--------|-------|
| branded primitive under `FrozenDeep` | ⛔ becomes a mapped record | ✅ unchanged |
| plain primitive, nested write, array `.push` | unchanged | unchanged |
| where the type lives | a local declaration in one sdk | one shared export |
| svc-chat's reported shape | carries a pnpm patch | imports and ships |

⚠️ the last row covers the shape #48 reports. a payload one array-field away still refuses a
mutable sink — a correct refusal with a different cause and remedy (case 8).

### the aha

> "frozen" should mean *you cannot change it*, never *it stops to be what it was*.

a primitive has no interior to freeze. to leave it alone is the only honest answer.

### what the walk found

- **a second wall, one field from the first** (case 8). add `tags: string[]` and the forward is
  refused again — by the array, never the brand. tsc's message names the field and prints
  `readonly lastMessageAt: Stamp`, so the error refutes "the fix did not land" on its first line.
- **#48's own arms repeat the defect** — an arm whose `infer` is wider than its input returns the
  wider type. the primitive arm did it to a brand; the array arm to a tuple. F9 closes it.
- **`FrozenDeep` guards the property reach; #48 left the method reach open** (`map.set`). F3
  closes it.
- **an array of branded primitives** (case 4 `[t4]`) — the same defect one container down; #48's
  clamp does not reach it.
- **five rejection rules** (I1–I5) hold the 27 forbidden cells; the widest, I2: *`readonly` sits on the
  slot, never on the value.*

## mental model

- **to a friend**: *"`Readonly`, but all the way down — and a branded string stays a string."*
- **analogy**: `Object.freeze`, deep, with the type to match — `asFrozenDeep` is the freeze,
  `FrozenDeep` is what it returns.
- **their words vs ours**: humans say *"deep readonly"*; we say `FrozenDeep`, named for the runtime
  freeze it types. `Frozen*` names the family; `asFrozenDeep` is the one way in.
- **the misread**: *"I cannot pass it to a function that mutates."* true only where an array sits
  in the shape (case 5).

## evaluation

### against the done-when

| done-when | how the vision reaches it |
|-----------|---------------------------|
| exported from the root | `FrozenDeep`, `FrozenMap`, `FrozenSet` from `src/types/FrozenDeep.ts`; `asFrozenDeep` from `src/companions/asFrozenDeep.ts` (F8, F14, case 6) |
| #48's clamp in the suite | cases 1–4, plus clamps for the grid's finds and each verdict |
| the companion agrees with the type | per shape, a unit test pairs the type refusal (`@ts-expect-error`) with the runtime throw (`getError`) — plain object, array, tuple, function prop, `map.set`, `set.add`; plus same-reference, primitive passthrough, and a cycle |
| the clamp bites | case 7. measured: the assign-back assertions go red; the forward assign stays green |
| released to npm | human gate per `.bounds` |

### pros

- the primitive arm diverts only branded intersections; plain primitives already fell through
  (premise 17). **no regression surface** from the fix.
- zero dependencies; the types cost no runtime, and the companion costs one walk per value.
- fixes the structural cause: a general type had a local home, so it only saw one repo's shapes.
- **type and freeze ship from one file pair, one repo** — the drift that produced this defect has no
  seam left to occur at, once `sdk-aws-lambda` delegates to `asFrozenDeep`.
- the repro that proves the fix is the test that keeps it.

### cons

- **`asFrozenDeep` mutates its input.** it freezes in place and returns the same reference — the
  `as*` prefix reads as a pure cast, and this one has an effect on the value passed in. the jsdoc
  states it. (F11)
- **a frozen `Map` / `Set` carries own-prop shadows.** `map.set` is an own function that throws,
  not `Map.prototype.set`; a reader who inspects the instance sees three extra non-enumerable
  props (map: `set` / `delete` / `clear`; set: `add` / `delete` / `clear`). (F12)
- **a hand-off to a mutable object sink compiles** — typescript ignores `readonly` in structural
  assignability. the jsdoc states it; case 5 `[t1]` clamps it.

### edgecases

| edgecase | behavior | evidence |
|----------|----------|----------|
| branded primitive — string, number, boolean — any depth | unchanged | premises 1–4; edge E7, E8 |
| literal (`'shredder'`), optional brand | not widened; stays optional and branded | edge E9, E10 |
| optional prop · union · `unknown` | `a?` kept · distributes · no collapse to `never` | premises 13, 14, 16 |
| `void` · `never` · `any` | each round-trips | edge E1–E3 |
| recursive type · index signature · symbol key | terminates deep · readonly · readonly | edge E4–E6 |
| branded object | still deep readonly | premise 12 |
| class with `#private` fields | ⛔ refuses assign-back — the mapped type drops privates | round-4 E8 |
| ⚠️ a write through `any` | compiles — a freeze has no reach into `any` | A105–A108 |
| ⚠️ a frozen array after `Array.isArray` | `.push` compiles again — the guard's `any[]` restores it | round-4 U2, U4 |
| assign into a mutable **object** sink | ✅ compiles — the bound | variance rows A–C |
| assign into a mutable **array** sink | ⛔ refused | variance rows D, E |

**pit of success**: one generic, no options — a caller cannot hold it wrong. the only surprise is a
stronger guarantee than it gives, so the jsdoc states three bounds (F4, a done-when): a mutable
object sink, a write through `any`, a frozen array after `Array.isArray`.

## what is awkward?

- **a "deep readonly" that does not refuse a hand-off.** for object shapes, a mutable sink accepts
  a frozen value. a branded readonly would enforce it and break every consumer that forwards an
  envelope. documentation plus a clamp is the right way round, and still feels weak.
- **`asFrozenDeep` is stricter than `Object.freeze`.** it refuses `map.set()` at runtime where the
  built-in does not, so the companion matches its type and departs from the primitive it is named
  after. a reader who knows `Object.freeze` well may still expect `set` to pass.
- **a raw `Object.freeze` still passes as a frozen value.** no gate forces a caller through
  `asFrozenDeep`; a hand-rolled `x as FrozenDeep<T>` carries the type with no freeze behind it.
- **the fix stops one field short of a common shape** (case 8). an adopter reads "branded
  primitives are fixed", adds `tags: string[]`, and meets a second refusal. the refusal is correct;
  the confusion comes from how cleanly the fix reads. docs are the only remedy — the message is
  typescript's.
- **the route ships more than its spec.** #48 is the source of truth; three arms depart from it by
  verdict, and the `Frozen*` family plus `asFrozenDeep` extend it. the deviation is recorded here and in the fulcrums; #48 should be
  updated to match what ships.
