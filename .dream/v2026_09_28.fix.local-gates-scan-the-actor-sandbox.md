# 🌙 dream: exclude `.agent/` from the local test and lint scans

> **half closed at 5.3.** `.depcheckrc.yml` now carries `ignorePatterns: [.agent]`; its declapract
> practice is a `CONTAINS` check whose fix only adds absent `ignores`, so the key survives an
> upgrade. **what remains**: `jest.unit.config.ts` matches its practice file exactly (no
> `.declapract.ts`, so an equals check), so its `testPathIgnorePatterns` fix belongs upstream in
> `declapract-typescript-ehmpathy`, not here.

- **kind**: fix
- **owner**: `ehmpathy/type-fns` (and every repo with the same declapract config)
- **caught**: 2026-09-28

## .the cue that fired

peer review round 2 was in flight, so I ran the repo's own gates as a wait that produced
information. two of them fail, and neither failure is this repo's code:

```
rhx git.repo.test --what unit --mode apply --thorough
  Test Suites: 6 failed, 19 passed, 25 total
  Tests:       1 skipped, 73 passed, 74 total
```

every one of the 6:

```
Cannot find module 'claude-code/testing' from
  '.agent/.actors/actor.via.hash=e7ea452d/brain/.claude/plugins/marketplaces/
   claude-plugins-official/plugins/code-modernization/tests/hostile.test.ts'
```

`rhx git.repo.test --what lint` fails the same way — depcheck reports an absent `claude-code`
dependency, sourced from the same vendored plugin.

## .the gap, precisely

the actor sandbox lives **inside** the repo tree at `.agent/.actors/`. jest and depcheck walk the
working tree, so both pick up a vendored third-party plugin that has its own `package.json`, its
own test suite, and none of its dependencies installed here.

three facts, each checked rather than assumed:

| claim | the command | the result |
|-------|-------------|------------|
| the dir is gitignored | `git check-ignore -v <file>` | ✅ `.agent/.actors/.gitignore:7:/*` |
| no file under it is tracked | `git ls-files .agent/.actors/ \| wc -l` | ✅ `0` |
| this repo's own suites pass | the run above | ✅ **19 passed, 73 tests green** |

⇒ **CI never sees this.** it clones from git, and git holds zero files under that path. the failure
is local-only, and it is **systematic rather than personal**: any agent who works this repo through
the rhachet actor system materializes the same sandbox and meets the same two red gates.

### why that costs something

a gate that is red for a reason unrelated to your change is a gate you stop to read. the second
time it happens you stop to read it more slowly, and the third time you stop to read it not at all
— which is the moment it stops to protect anything. **a permanently-red local gate is worse than an
absent one.**

## .the shape of the fix

exclude the sandbox from both scanners. two one-line edits:

```js
// jest.config.js
testPathIgnorePatterns: ['/node_modules/', '/.agent/'],
```

```jsonc
// .depcheckrc (or the depcheck invocation in package.json)
"ignorePatterns": [".agent/**"]
```

⚠️ **check the declapract provenance before you edit.** if `jest.config.js` is a declapract-managed
file, the edit belongs **upstream** in the practice, or the next `declapract upgrade` reverts it.
that is the one thing that could turn a two-line fix into a real task.

⇒ and the honest alternative worth one minute of thought first: **should the actor sandbox live
inside the repo tree at all?** the scan exclusion treats the symptom; a sandbox outside the tree
removes the class (`rule.require.solve-at-cause`). the exclusion is still right for today, because
the sandbox location is not this repo's to choose.

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

- **safe?** ✅ — two config lines over a path with zero tracked files. it cannot change what CI runs.
- **clean?** 🔴 **no.** it lands in `jest.config.js` and the depcheck config — tracked prodcode
  configuration that a **vision** stone has no other reason to open. the route's whole diff right
  now is markdown under `.behavior/`, and it is mid-peer-review; a prodcode config change smuggled
  into that diff is the exact "ripples into files this change never intended to open" case the
  CLEAN question refuses.

⇒ safe but not clean ⇒ defer, and record. **no fulcrum is owed**: the deferral turns on scope, not
on a judgment about ripple cost that a council would want to overturn.
