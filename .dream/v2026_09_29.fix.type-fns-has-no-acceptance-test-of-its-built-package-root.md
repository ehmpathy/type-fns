# 🌙 dream: an acceptance test of type-fns' built package root

> **closed at 5.3.** `src/index.acceptance.test.ts` exists, imports `../dist`, and bites the built
> `.d.ts`. **what remains**: ci's acceptance job needs the grant in
> `5.3.verification.handoff.v1.to_foreman.md`.

**kind** = fix · **owner** = ehmpathy/type-fns · **caught** 2026-09-29

## .the cue that fired

self review `role-standards-coverage` on `v2026_09_27.fix-frozen-deep-primitive-passthrough`:
`rule.require.test-coverage-by-grain` asks a contract (here, the package's public exports) for an
acceptance test. type-fns has a `jest.acceptance.config.ts` and zero `*.acceptance.test.ts` files.

## .the gap, precisely

every export is tested from `src/`. none is tested from `dist/`, the artifact a consumer imports.
so a defect in `build:compile` — a `tsc-alias` path left unrewritten, an export line lost, a
runtime `require` of a type-only module — would ship green.

this route checked it by hand once (`npm run build`, then read `dist/index.d.ts` and
`dist/companions/asFrozenDeep.{js,d.ts}`): all three new exports on the root, the `@src/` alias
rewritten to `../types/FrozenDeep`, the type import erased from the js. a hand check is not a clamp.

## .the shape of the fix

`src/index.acceptance.test.ts`, blackbox via the built artifact (`rule.require.blackbox-via-selflink`):

- `require('type-fns')` (self-link) loads; `asFrozenDeep`, `assure`, `omit`, `pick`, … are functions
- a `.d.ts` probe compiled against `dist/index.d.ts`: `FrozenDeep`, `FrozenMap`, `FrozenSet`,
  `ArrayWith`, `HasMaybe`, … are found
- a snapshot of the root's runtime export names, so an addition or a loss shows in review

## .why it is not done in this round

- **clean ✗** — `jest.acceptance.env.ts` sources keyrack in `strict` mode once `.agent/keyrack.yml`
  exists. a first acceptance suite pulls that credential path into ci for a patch release whose
  wish is one type. it ripples into ci config, not only into this diff.
- **safe ✓** — a test adds no behavior.

⇒ the deferral is a judgment about ripple, recorded in review `role-standards-coverage` for the
council.
